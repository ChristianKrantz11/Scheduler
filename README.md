# Work Day Scheduler

A simple daily planner for a standard 8 AM – 5 PM workday. Type an event into any hour and save it. Your schedule stays put after you refresh the page.

**[Launch Scheduler](https://christiankrantz11.github.io/Scheduler/)**

## Features

- Today's date and time shown at the top of the page
- Hourly time blocks from 8 AM to 5 PM
- Color-coded blocks:
  - Past hours
  - The current hour
  - Future hours
- Click a block to type an event, then press its save button
- Events are saved in the browser's `localStorage` and persist after a refresh

## Built With

- HTML, CSS, JavaScript
- [jQuery](https://jquery.com/)
- [Moment.js](https://momentjs.com/)

## Running Locally

No build step is needed.

1. Clone the repo:
   ```bash
   git clone https://github.com/ChristianKrantz11/Scheduler.git
   ```
2. Open `index.html` in your browser.

## User Story

```
AS AN employee with a busy schedule
I WANT to add important events to a daily planner
SO THAT I can manage my time effectively
```
